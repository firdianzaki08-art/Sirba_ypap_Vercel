# SIRBA – Sistem Reimbursement BBM Avicenna

Situs statis (HTML/JS) dengan backend Supabase. Di-deploy otomatis oleh Vercel dari branch `main`.

- `index.html` – aplikasi utama (login AP, Kepala TU, GA, superadmin)
- `ajukan/index.html` – formulir pengajuan publik tanpa login
- `form-pdf.js` – pembuat PDF formulir
